# N.I.A 决策手册（数字小广）

决策层做 N.I.A（NEXT IDOL AUDITION）时用的打法底稿。规则和数值以社区攻略原文为准，机制和数字见 [hajime-nia-mechanics.md](hajime-nia-mechanics.md)。

每条后面标了出处。〔社 xx〕是社区攻略（代号见文末）。〔GK〕是 GKMSProject 的实测。〔我们〕是我们自己定的或实机看到的。规则在决策层里的 id 写成 `nia.xxx`，对应 `src/hiro/defaults/hajime_nia_rules.json`。

注意口径：wikiwiki 的两篇（ww-NIA 2025-05、ww-NIA支 2025-09）是给コンテスト厳選（控制回忆里技能卡的抽选）写的，有些做法会故意压低评价。我们要的是评价值和稳定通关，冲突时以 game8 为准。

## 目标与评分

- 三场试镜（PRO 在第 9、18、27 周）都要拿**第 1 名**〔社 g8-NIA〕。
- 评价 = floor(属性和 × 2.3) + 票数折算。票数在 2 万以内每票 0.1 分，越往后越少〔GK〕。属性上限 PRO 2000、MASTER 2600〔主〕。
- 第 1 名分数线（按最高档、而且已经把チャレンジP道具让对手 +40% 算进去）〔社 g8-NIAM〕：

| 场次 | PRO | MASTER |
|---|---|---|
| 1 次 | 2,800 | 3,500 |
| 2 次 | 23,000 | 40,000 |
| 最終 | 80,000 | 170,000 |

- 最終试镜分数过了衰减线，票数就涨得很少：PRO 约 20 万，MASTER 约 65 万〔社 g8-NIAM〕`nia.final_decay`。
- 〔我们〕2026-11-17 PRO 第一局（篠澤広）：1 次 ToNight 4,680 票 → 2 次 POP Fair 15,943 → 最終第 2 档（36,036 票时选的）第 1 名，最终评价 A 11,475。
- 〔我们〕2026-11-18 PRO 第二局：三场都选到最高档（1 次第 3 档、2 次第 3 档、最終第 4 档），最终评价 S+ 15,428，票数 86,919。中途停了几次（无 SKIP 的台词页、营业事件页报错），已转平台。

## 日程

- PRO 27 周，MASTER 26 周（去掉了 PRO 第 16 周的自主课）〔社 g8-NIA、ww-NIAM〕。
- 每周一种主行动，再加上一直可选的休む：自主课、営業、特別指導、お出かけ / 相談 / 差し入れ 几种〔我们〕。
- PRO 各行动的次数：自主课 8（审查基准第 1、2 位各 4）、営業 7、お出かけ 5、特別指導 4〔社 ww-NIA支〕。
- 休む 最多 4 次〔社 g8-NIA〕`nia.rest_limit`。
- 逐周表还没有，见机制说明第 7 节。

## 自主レッスン

- **总是上 SP**〔社 g8-NIA〕`nia.lesson_sp`。有几个 SP 时，选能触发 P 道具的那项，或者补缺的属性〔社 g8-NIA〕。
- 体力：通常 6、SP 8。体力不够消耗就上不了〔社 g8-NIA〕`nia.lesson_stamina`。所以営業之后要留 ≥ 8 体力〔社 g8-NIAM〕。
- 一个 SP 都不出，可能是支援卡编成有问题〔社 g8-NIA〕。
- 〔我们〕实机自主课是自动跑完的，只要点结算页。

## 営業

场所按颜色认（〔我们〕用户定：场所名读不出来不要紧，重点是认图标和颜色，对应到属性）：

| 颜色 | 场所 | 附带 | 票数 |
|---|---|---|---|
| 紫 | 商業施設 | 拿到的技能卡是强化过的 | 标准 |
| 青 | 企業イベント | 饮料 | 标准 |
| 黄 | 自治体イベント | 未强化卡 + P 点 50 | 标准 |
| 绿 | リゾート施設 | 体力 +10 | PRO 少约 30%；MASTER 只少 200–300 |

- **以黄、紫为主**〔社 g8-NIA、g8-NIAM〕`nia.sales_yellow_purple`。
- 体力不够、会耽误下周上课时去绿〔社 g8-NIAM〕`nia.sales_green_low`。MASTER 里绿和其它场所的票数差得少，更可以去〔社 g8-NIAM〕`nia.sales_green_cheap`。
- 反方意见：ww-NIA（コンテスト向け）说不去绿，票少了后面全吃紧〔社 ww-NIA〕`nia.sales_green_contest`。我们按 game8 的。
- 考试要用的饮料（ブーストエキス、プロテイン等）不齐时去青〔社 g8-NIAM〕`nia.sales_corporate_drinks`。
- 营业里三个选项分别涨 Vo / Da / Vi：支援卡集中在两项，营业的选项就补第三项〔社 g8-NIA〕`nia.sales_choice_fill`。
- 大成功（多 30% 票）的概率看属性合计：1 次前合计 ≥ 798、2 次前合计 ≥ 1468 时必定大成功〔社 ww-NIA〕。
- 〔我们〕实机规则：体力 12 时去黄、紫会掉到 8 以下，所以改去绿。

## オーディション选档

- 选**够得上票数门槛的最高档**，前提是有把握拿第 1。失败了可以降档再打〔我们，参考 MaaGakumasu〕。
- 档位门槛（篠澤広 PRO）：1 次 0 / 4000 / 9000 票，2 次 0 / 14000 / 25000，最終 0 / 28000 / 40000 / 57000（第 3、4 档还要亲爱度 14 / 17）〔主〕。
- コンテスト厳選的选法（不是我们的目标，只作参考）：1 次メロBang!，2 次 GAL★AXY，最終选 Quartet 不选 finale〔社 ww-NIA〕。
- 再挑戦：每场最多 3 次，只用免费的或已有的チケット〔我们的规矩〕。

## お出かけ

- 拿不准就选中间那项（删卡 + 饮料）〔社 g8-NIA〕`nia.outing_middle`。
- MASTER：优先级是 下（强化）＞ 中（删除）＞ 上（强化）＞ 中（换卡）。拿不准选花 P 点最少的「下」〔社 g8-NIAM〕`nia.outing_order`。
- MASTER：除了上课和营业的周，尽量外出（回体力，也能触发外出相关的道具和支援卡）〔社 g8-NIAM〕`nia.outing_default`。
- 三篇攻略说的「中间选项」内容不一样（删卡 + 饮料 / 换卡 / 删卡或换卡），选之前先看画面上的实际效果〔社〕。

## 相談、特別指導

- 1 次试镜前想把删卡和定制都做满，要 210–280P〔社 ww-NIA〕`nia.consult_budget`。
- 删卡：不带「レッスン中1回」的先删，「○○の基本」到最終前全删〔社 g8-NIAM〕`nia.delete_order`。
- 特別指導：给「用了以后加やる気」之类的卡定制「开始时加入手牌」〔社 g8-NIA〕。MASTER 一次能定制 2 张〔主〕〔社 ww-NIAM〕`nia.guidance_two`。
- 选了ワッペン时，没有要定制的卡也进特別指導〔社 ww-NIA〕`nia.guidance_wappen`。

## 试镜后的 P 道具三选一

- PRO：アノマリー以外选 N.I.Aワッペン 比较稳（ww-NIA 2025-05，MASTER 实装前写的）〔社〕`nia.pitem_wappen`。
- MASTER 1 次后：トートバッグ（企業营业给饮料）/ スマホリング（商業营业强化卡）/ パスケース（自治体营业 +40P）没有最强的；P 点总是不够，就选パスケース〔社 ww-NIAM〕`nia.pitem_passcase`。
- MASTER 2 次后：はつぼしブレスレット / N.I.Aライト / バンド。センス流派用ライト（好調）或バンド（集中）〔社 ww-NIAM〕。
- 〔我们〕3940a9 实现了试镜后的 P 道具选择（11-17）。

## 卡组

- MASTER 推荐外出型压缩：最后只留 3 张能循环的卡（两张「使用回数+1」+ 一张火力），其它都是带「レッスン中1回」的一次性卡〔社 g8-NIAM〕。
- 循环件例子：好印象是みんな大好き / オトメゴコロ / ラブリーウインク；やる気是ゆめみごこち / きらきら紙吹雪（やる気流派不能完全循环）〔社 g8-NIAM〕。
- N.I.A 的必拿卡表还没做，3940a9 在补〔我们〕。

## MASTER 特有

- チャレンジP道具最多带 3 个，换来对手分数提高。各道具的试镜加成合计配到 35–40%〔社 ww-NIAM〕`nia.challenge_bonus`。推荐「アイドル紹介用資料」+「おでかけ日傘」+ 第 3 格（NIATシャツ或 NIAバッグ，按偶像推荐效果选颜色）〔社 g8-NIAM〕。
- 开局有 N.I.Aキーホルダー：每拿 2 张技能卡，票数 +3000〔社 ww-NIAM〕。
- 属性上限 2600〔主〕（g8-NIAM 写的是 2300，以主数据为准）。
