# 初星助手界面改版：设计简报（2026-11-20 用户确认）

## 1. 是什么
初星助手的整体界面改版：和「初星攻略站」同一个牌子，但更像桌面程序。给不会写代码的学マス玩家，也给盯决策过程的熟手。

## 2. 最主要的动作
开局（选模式和参数，点确认），然后瞥一眼就知道打到哪、为什么。

## 3. 方向
- 场景：白天或晚上室内灯下，游戏窗口在屏幕一边跑，助手在另一边；玩家偶尔瞥一眼，要拍板时才点。→ 浅色，不做暗色。
- 配色：Restrained。攻略站的白底、中性灰字和线；学マス橙只给主按钮、链接、选中；Vo / Da / Vi 只出现在数据里。
- 参照：Raycast、Linear（桌面密度、状态表达）；初星攻略站（变量、字体、shadcn 组件、Vo/Da/Vi 斜杠标志）。

## 4. 范围
整个程序，改到可发布；组件从攻略站搬 shadcn（底层 Base UI）。

## 5. 布局
- 左侧栏：「开局」（主入口）、「编成方案」、信息（支援卡 / 回忆 / 偶像卡 / 好感度 / 游戏设置 / 资料库）、设置；下面是最近的对话；底部是账号数值和模型。
- 中间：任务记录式的对话（不是聊天气泡）：用户的话是一行指令样式，助手的回答是段落 + 结果块；底部输入框和快捷指令。
- 右栏：当前任务（实时画面、阶段、步数、暂停 / 接手 / 停止），没任务时显示账号概况。
- 开局页：五种模式一行一个（不是卡片网格），点开展开参数（偶像卡、难度、编成号默认按方案、层数、日常项），下面内联确认条，不弹窗。
- 驾驶舱：画面 + 步骤时间线（理由 + 来源标签）；结束后成绩条（每场分数用粗斜体数字）+「看复盘」。

## 6. 状态
空、加载骨架、出错（原因 + 下一步）、待确认、进行中、已暂停、你在接手、结束（成绩）。

## 7. 交互
动游戏的操作都先出内联确认；动效 150–250ms、只表达状态；尊重减少动态效果。

## 8. 文案
平实、短；不用英文页面名和内部编号；错误写原因和下一步。
