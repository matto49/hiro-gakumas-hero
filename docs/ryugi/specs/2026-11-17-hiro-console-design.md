# 数字小广控制台：设计稿（2026-11-17 已批准）

设计讨论（两轮问答 + 两轮画板）的结论。标「我定的」的是实现者代为做的决定。

## 1. 为什么做

hiro-gakumas-hero 已经能自己打完 H.I.F（选拔评价 SS、本战多次夺冠），但现在要用它，得会命令行、环境变量、编成号、设备开关，还要会看日志判断停在哪。这个控制台要做两件事：

- **把学マス的信息收全、展示清楚**：账号里有什么（等级、偶像卡、支援卡、回忆、好感度……），游戏里每样东西是什么（卡牌、P 道具、饮料……）。这是卖点。
- **让 agent 用这些信息完成游戏的各个部分**：打 H.I.F、日常、偶像之路、初；小白在应用里打一句话就行，熟手可以让自己的 Claude Code / Codex 调用同一套工具。

成败标准（你定的）：**对 AI 一窍不通、只会申请 DeepSeek API Key 的玩家，能把系统正确跑起来**。做不到就算失败。

## 2. 目标、不做的、坚决不做

| 类别 | 内容 |
|---|---|
| 目标 | 一个桌面程序：首次打开有向导，装好环境、连上游戏、配好模型；之后用对话让小广查信息、开局、领日常，过程和结果都看得到，需要拍板时弹卡片。 |
| 目标 | 一套工具（类 CLI 命令 + skill 说明），应用内置的 agent 和外部 agent 用的是同一套。 |
| 第一版不做 | 远程管理另一台电脑；多账号切换；排程（到点自动跑）；手机端；活动 / 剧情进度和历史成绩面板（放第二版）。 |
| 坚决不做 | 花ジュエル、放弃培育（任何设置都打不开）；读种子或存档里的隐藏信息；让 agent 或界面看到账号密码明文。 |

## 4. 整体结构

三层：桌面程序（界面 + 内置 agent）、工具层（一个命令行程序，所有能力都从这里出）、hiro 现有代码（识别、设备、决策、主循环）。界面和内置 agent 都只通过工具层干活，外部 agent 也一样，所以三方看到的能力完全一致。

- **工具层是 Python 写的命令行**（我定的）：逻辑都在 hiro 里，用 Python 直接调用最省事；每条命令输出 JSON，长任务（开局、扫描）输出事件流（每一步一行 JSON），界面和 agent 都靠这个实时更新。
- **代码放在 hiro-gakumas-hero 仓库里**（我定的）：你定过只留一个仓库，所以桌面程序放在仓库的 `app/` 目录，工具层放在 `src/hiro/cli/`，skill 说明放在 `skills/`。
- **Python 环境由向导装**（我定的）：程序自带 uv，第一次打开时下载 Python 和依赖到程序自己的目录，用户不用装 Python。

## 5. 主窗口（对话为主）

（画板 q2-a）

- **左栏**：「新对话」，下面是对话和任务列表（一句话一个任务，进行中的局标橙色）；底部是账号摘要（PLv、AP、ジュエル）、当前连接的设备、当前模型。
- **中间**：和小广的对话。agent 的回答里嵌卡片，第一版有这几种：编成卡（偶像卡图、支援卡 / 回忆编成号、技能卡和 P 道具图标）；对局卡（缩略游戏画面、当前阶段、最近几步和理由，「打开这局的驾驶舱」）；确认卡（需要你拍板的事，例如开本战，两个按钮）；信息卡（查询结果的表格或卡片网格，例如「我的 SSR 支援卡」，可以点进对应信息页）；出错卡（用白话说停在哪、为什么、你可以做什么：重试 / 我来接手 / 看日志）。底部输入框下面有几个建议问题，小白可以直接点。
- **右栏**：三个页签：游戏画面（实时截图 + 当前页面名 + 关键数值）、账号（信息面板入口）、资料库（搜索入口）。
- **驾驶舱**：从对局卡点开的整页，就是第 1 轮选的 B：实时画面、每一步做了什么和理由（标出是规则、算法、LLM 还是兜底定的）、状态、暂停 / 我来接手 / 看复盘。
- **信息页**：偶像卡、支援卡、回忆、资料库各一页，卡片网格 + 筛选（参考画板 q2-b 的样子），从右栏或信息卡进入。

## 8. 内置 agent 和模型配置

- **服务商**：照 magpie 的「服务商 + Key + 模型」，简化成三家：DeepSeek（填 API Key）、Codex（用户已登录的 codex 命令行，或填 OpenAI Key）、Claude（用户已登录的 claude 命令行，或填 Anthropic Key）。向导里默认 DeepSeek，附申请 Key 的图文步骤。
- **agent 怎么干活**（我定的）：程序里一个简单的工具调用循环：把工具层的命令描述成工具给模型，模型选工具，程序执行、把 JSON 结果交回模型，直到回答用户。对局本身不靠这个循环：开局后由 hiro 主循环打，agent 只负责发起、看进度、转述和转达确认。
- **不填 Key**：对话框变成「快捷指令」模式，只能点建议按钮（开一局、领日常、扫描），对局里的决策只用规则和算法。
- **权限**：每个工具标风险等级。查信息直接执行；开局、扫描这类会动游戏的，第一次在对话里出确认卡；花ジュエル、放弃培育的工具根本不存在。

## 9. 外部 agent（熟手）

- 工具层命令本身就能在终端里用（例如 `hiro info supports --rarity SSR`、`hiro run hif --idol …`、`hiro run status`），输出 JSON。
- `skills/` 里写好 skill：每条命令什么时候用、参数、返回什么、哪些要先问用户。熟手把仓库交给 Claude Code / Codex，读 skill 就能用。
- 外部 agent 和应用同时开着时，两边操作的是同一个游戏：同一时间只允许一个对局在跑，工具层用锁保证。

## 10. 密码管理

- 账号密码只能由人在设置页填写，存进系统钥匙串（Mac 钥匙串 / Windows 凭据管理器）（我定的）。
- 界面上永远不显示明文（只显示「已保存」）；agent 和工具层只能调用「复制到剪贴板」：值带敏感标记写进剪贴板，45 秒后自动清空。
- 用途：游戏掉登录、需要输账号密码时，程序把账号、密码依次复制到剪贴板粘贴进去。工具层的日志和对话记录里不写入任何值。

## 11. 新手向导

1. **装环境**：自动下载 Python 和依赖、游戏主数据、识别素材，显示进度；失败时用白话说原因（网络、磁盘空间）。
2. **选平台、连游戏**：Mac：检查是不是 hguandl 分支 PlayCover、maaTools 开没开，没开就给截图教程。Windows DMM：检查游戏窗口、按显示器调窗口大小，需要管理员时说明为什么要点 UAC。MuMu：找模拟器、连 adb，标「测试中」。
3. **关游戏声音**：检测游戏内声音设置，没关就提示关（不动系统音量）。
4. **配模型**：默认 DeepSeek：图文教怎么申请 Key，粘贴后点「测试」，成功才进下一步；可以跳过（只用快捷指令）。
5. **（可选）存账号密码**：说明用途和保管方式，可以跳过。
6. **第一次扫描账号**：扫首页数值、偶像卡、支援卡、回忆，扫完进主窗口，对话里放一张「你的账号概况」信息卡。

验收方式：找一位只会申请 DeepSeek Key 的人，在没人帮忙的情况下从下载安装包走到打完一局 H.I.F 选拔；卡住的每个地方都改向导。

4. **新手向导、密码管理、安装包**（Mac 磁盘镜像、Windows 安装程序），找一位小白实测。
5. **日常补全、偶像之路接入**。
6. **初**（新做培育流程）。

## 12a. 实现约束（检查后补的）

- **识别**：游戏固定日服日文界面（汉化补丁不支持，见第 6 节）。所有平台的截图先换算成 720×1280 逻辑画面再识别，同一套模板和 OCR；Mac PlayCover 和 Windows DMM 实机验证过，MuMu 只有离线测试，所以标「测试中」。
- **依赖**：考试引擎的 Rust 部分已经由 CI 出 Windows / macOS / Linux 预编译包，向导用 uv 装 Python 依赖时直接取预编译包，用户机器上不编译。国内网络下载 Python、依赖、主数据时自动换镜像（我定的）。
- **后台进程**（我定的）：对局、扫描交给一个常驻后台进程（hiro 服务）跑；命令行只是它的客户端（本机端口通信），没有在跑时命令行会自己拉起它。所以应用里开的局在终端里看得到，终端里开的局应用也看得到、能接手；同一时间只跑一个对局或扫描。关掉主窗口时程序退到托盘，对局继续；从托盘退出程序时，先暂停在安全的地方再退出。
- **确认卡在工具层拦**（我定的）：要确认的命令（开局、开本战、扫描等）第一次执行时返回「待确认」和一个编号，应用把它显示成确认卡，用户点了才真正执行；外部 agent 拿到「待确认」时要先问用户。内置 agent 不管是 DeepSeek 的工具调用，还是 Codex / Claude 命令行模式（这两种当成外部 agent，用 skill + 命令行跑），都绕不过这一关。
- **实时画面和接手**：驾驶舱的画面来自设备层截图（Mac 走 MaaTools，DMM 走 MaaFramework，都不要求游戏在前台，但 DMM 窗口不能最小化），约 1 秒一张。「我来接手」时主循环停在检查点、不再点击；点「继续」时新主循环从当前画面重新判页接着打。
- **自动登录的做法**（我定的）：一次只往剪贴板放一个值（先账号、粘贴后再放密码），由程序把粘贴操作发到游戏的登录框；平台不支持自动粘贴时，对话里出卡片提示用户在登录框粘贴。剪贴板 45 秒清空，单个值够用。
