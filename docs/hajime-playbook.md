# 初 决策手册（数字小广）

决策层做初（定期公演『初』）时用的打法底稿。规则和数值以社区攻略原文为准，机制和数字见 [hajime-nia-mechanics.md](hajime-nia-mechanics.md)。

每条后面标了出处。〔社 xx〕是社区攻略（代号见文末）。〔我们〕是我们自己定的或实机看到的，没有社区出处。规则在决策层里的 id 写成 `hajime.xxx`，对应 `src/hiro/defaults/hajime_nia_rules.json`。

## 目标与评分

- 主目标：中間、最終都过线（前 3 名）。最終拿第 1 名才有高评价，而且第 1 名每项属性 +30〔社 g8-試験、ww-初M〕。
- 评价 = floor(属性和 × 2.3) + 名次分（第 1 名 1700）+ 最終分数分段折算。分数越高折算越少：5000 分以内每分 0.3，到 4 万以上每分只有 0.01。所以**先堆属性，最終分数够第 1 名、够 A+ 就行**。
- 参考线：
  - PRO A+：属性合计约 3000（二极 1200 / 1200 / 600 或一极 1400 / 900 / 700），最終约 15,500 分〔社 g8-A+〕。
  - 属性合计 3010 时，A+ 要 15,262 分、S 要 92,100 分；合计 3410 时，S 只要 25,000 分〔社 ww-初M〕。
  - 属性目标：PRO 3100–3200，MASTER 3400–3900〔社 ww-初M〕。
- REGULAR：属性上限 1000，中間 900 分封顶。第一阶段只要求打通（零介入回到首页），分数先不追〔我们〕。

## 日程

- 周数：REGULAR 13 周，PRO 16 周，MASTER 18 周〔社 g8-PRO〕。
- MASTER 有完整周表，三种随机：第 7 周追い込み，第 8 周中間，第 17 周追い込み，第 18 周最終；第 1、2 周是 MASTER 专用授業〔社 ww-初M〕。数据在 `vendor/gakumas-player/data/schedules/hajime_nia.json`。
- REGULAR 周表（我们一局实机还原，篠澤広）〔我们〕：1 课程，2 活動支給 / 授業，3 课程 / 授業，4 外出 / 相談，5 追い込み，6 中間，7 活動支給 / 外出，8 授業 / 外出，9 课程，10 课程 / 授業，11 活動支給 / 外出 / 相談，12 追い込み，13 最終。
  - 和社区提示一致：外出推荐第 4 周（中間前 2 周）、第 7 周（中間刚考完）、第 11 周（最終前 2 周）〔社 g8-外出〕；SP 课可能出现在第 1、3、9、10 周〔社 g8-SP〕。
- PRO 的周表原文是图片、按偶像各不相同，还没有〔社 g8-PRO〕。
- 考试前一周是追い込みレッスン〔社 g8-レッスン〕。

## 选行动

按优先级排：

1. **课程、授業优先**。体力管理的目标是每周都能上课程或授業〔社 g8-PRO〕`hajime.lesson_first`。
2. SP 课出现就上，涨得多〔社 g8-SP〕。
3. 追い込み选考试加成最高的属性〔社 g8-PRO〕`hajime.oikomi_bonus`。
4. 课程至少要 15 体力，不够时先回体力〔社 g8-レッスン〕。
5. 没有课程和授業的周：
   - P 点 ≥ 100 选外出（回得多，还带饮料或卡）〔社 g8-外出〕`hajime.outing_vs_rest`；
   - P 点不够就休息〔社 g8-休〕`hajime.rest_when`。
6. 体力掉了一半（或掉了 15 以上）再外出〔社 g8-外出〕`hajime.outing_when`。
7. 满体力不能休息〔社 g8-休〕`hajime.rest_full`。满体力也别外出〔我们，3940a9 2833252〕。
8. MASTER：外出随机性太大，基本不选〔社 ww-初M〕`hajime.master_outing_avoid`；第 6 周以后才能休息〔社 ww-初M〕`hajime.master_rest_week6`。

回体力优先用不占一周的办法：打出パーフェクト（剩下的回合每回合回 2）、支援卡和回忆的回复、元気抵扣、带回复效果的技能卡〔社 g8-PRO、g8-レッスン〕。

## 授業

- 涨的属性和数值都随机（20 / 30 / 40 / 55 / 80 / 110）〔社 g8-授業〕。
- PRO 起可以选「トラブル追加」：往牌堆加一张眠気，换这个授業的最高值〔社 g8-授業〕`hajime.study_avoid_trouble`。
- 想涨的属性不是最高值时，可以选体力消耗少的那项〔社 g8-授業〕。

## 相談、活動支給

- 相談删卡：第 1 次 100P，第 2 次 125P；强化同价〔社 g8-PRO〕`hajime.consult_price`。
- 中間以后，P 道具选ブレスレット，用它在 SP 课后强化卡，P 点省下来买饮料和卡〔社 g8-PRO〕。
- MASTER 有强制的活動支給周；P 点约是 PRO 的 2 倍，可以买「強化済み」〔社 ww-初M〕。

## 卡组

- 流派按偶像擅长的 buff 走：やる気、好印象、集中、好調〔社 g8-PRO〕。篠澤広是やる気〔社 g8-試験〕。
- 见到 PLv25 解放的「私がスター」「国民的アイドル」「アイドルになります」就拿〔社 g8-A+〕。
- 相談里删掉不要的卡，强卡更容易进手〔社 g8-PRO〕。
- 选卡、删卡的具体评估走决策层的通用流程（社区评级 → LLM → 兜底）〔我们〕。

## P 道具、饮料

- 中間过关后的 P 道具，ロジック选マスコット / キーホルダー / ブレスレット，センス选 Tシャツ / 手帳 / ブレスレット。やる気流派推荐ブレスレット〔社 g8-PRO〕。
- P 道具优先用在追い込み和 SP 课里打パーフェクト，不要留给考试〔社 g8-PRO〕。
- 饮料：课程里随时可以喝，强饮料（初星ホエイプロテイン等）留到最終〔社 g8-試験〕。
- 饮料满了（3 瓶）又给新的：值得换才换。〔我们〕持有的饮料没认全时程序会停下等人。2026-11-17 那次是手动点「受け取らない」→「決定」跳过的。

## 考试出牌

- 每回合有指定属性。加成高的回合打参数大的卡，加成低的回合打元気、buff 做准备〔社 g8-試験〕。
- 不跟游戏的发光推荐〔我们，和 H.I.F 一样〕。
- 每场考试最多再挑戦 3 次，只用免费的或已有的チケット，不拿マニー买〔社 g8-試験；我们的规矩〕`hajime.exam_retry`。
- 出牌目前是 UINet。GNRPA 搜索做好了，开关默认关；初的搜索目标是前 3 名，REGULAR 中間按 900 分封顶来算〔我们〕。

## 支援卡、编成

- 支援卡按审查基准第 1、2 位属性分配，二极育成〔社 g8-A+〕。
- SP 率支援卡和 P 偶像特训（2 段 +5%、6 段 +10%）提高 SP 出现率〔社 g8-SP〕。
- あさり先生（きみは、自慢の生徒です）两篇说法不同：g8-PRO 推荐带，g8-A+ 说优先度低。我们现在的编成方案没有特别处理她〔社〕。
- 编成走 `formation_plan` 的方案，不用おまかせ〔我们〕。
