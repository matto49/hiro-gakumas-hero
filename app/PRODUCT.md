# Product

初星助手（2026-11-20 起；原名数字小广控制台）：学マス（学園アイドルマスター）的桌面助手。收集账号里的信息、展示游戏资料，让 AI 替玩家完成游戏里的各项任务（H.I.F、初、N.I.A、偶像之路、日常）。和网站「初星攻略站」是同一个牌子：网站查资料，助手替你打。仓库是 hiro-gakumas-hero，命令行工具叫 `hiro`。

## Register

product

## Users

不会写代码的学マス玩家，只会申请 DeepSeek API Key 也要能用起来（设计稿的成败标准）。另有熟手：会盯着每一步决策和理由，或者用自己的 Claude Code / Codex 调同一套 `hiro` 命令。

使用场景：游戏窗口在屏幕一边跑，助手在另一边。一局四十多分钟，玩家偶尔瞥一眼进度，只在要拍板时（开局、开本战、写编成）出手。

他们来这里做五件事：
- 开局：选模式、偶像卡、编成，点确认，让它自己打；
- 看进度：现在打到哪、每一步为什么这么选（规则 / 算法 / LLM / 兜底）；
- 查信息：我有什么支援卡、回忆，资料库里某张卡是什么效果；
- 准备：按攻略出编成方案、写进游戏、检查快进设置；
- 局后：看成绩、看复盘。

## Product Purpose

把 hiro-gakumas-hero 已有的能力交到普通玩家手里：不用命令行、环境变量、编成号，也能让 AI 把游戏的各项任务打完，并且看得到它在做什么、为什么。

成功的样子：新手装好、填 Key、点「开局」，四十分钟后看到成绩卡；熟手打开驾驶舱，一眼看出这一步是谁定的、理由是什么。

## Brand Personality

和初星攻略站同一个牌子，但更像桌面程序：白底、中性灰的字和线，学マス橙只用在主按钮、链接、选中状态；Vo / Da / Vi 回合属性条、粗斜体的分数数字、偶像小缩略图，用游戏自己的视觉语言。布局紧凑，像原生工具。

文案平实、短：像懂行的玩家写给玩家；出错时用白话说停在哪、为什么、可以做什么。

三个词：放心、清楚、像学マス。

## Anti-references

- 聊天软件的样子：大气泡、头像一排排、对话占满屏幕（助手的回答是任务记录 + 结果，不是闲聊）
- 千篇一律的 SaaS 后台：大数字卡片、渐变强调、一排排相同的卡片
- 霓虹暗色的「电竞风」；不做暗色
- 立绘和截图堆满界面（偶像只用小缩略图，游戏画面只在「游戏画面」区域）
- AI 腔文案：三连排比、每段先复述标题

参照：Raycast、Linear 的桌面密度和状态表达；初星攻略站的配色、字体和游戏元素。

## Design Principles

1. 看得到在做什么：每个任务都有状态、最近几步和理由，谁定的标出来。
2. 动游戏的事先问：开局、写编成、扫描都要点确认；花ジュエル、放弃培育永远做不到。
3. 用玩家的语言：卡名、图标、回合属性用游戏里的样子，不用内部编号和英文页面名。
4. 新手不用打字也能用：每个能力都有按钮入口，对话是加速，不是唯一入口。
5. 出错要给下一步：每个错误都写原因和能点的下一步。

## Accessibility & Inclusion

- 中文界面；卡牌、饮料、偶像用游戏里的日文原名。
- 对比度达到 WCAG AA。
- 颜色不作为唯一区分：Vo / Da / Vi、任务状态、决策来源都有文字。
- 尊重 prefers-reduced-motion。
